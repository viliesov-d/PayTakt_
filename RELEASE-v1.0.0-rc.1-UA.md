# PayTakt v1.0.0-rc.1 — передреліз

**Мета:** підготувати UI до 1.0, зберігши працюючу логіку v0.9.4.1.

### Візуальні зміни
- Верхня навігація замість лівої вертикальної панелі; на вузьких екранах вона розгортається кнопкою меню.
- Стиль «Зміни»: темно-синя шапка, лаймові кнопки, міні-календар у головному блоці, білі картки та м'який фон.
- Узгоджені відступи, акценти, картки, кнопки, поля й календар.
- Кнопка вибору робочого простору та вибір теми завжди доступні у верхньому рядку.
- Прибрано зайві згадки Firebase/Firestore зі звичайних статусів. Повідомлення про помилки автентифікації/доступу залишено.

### Безпека та сумісність
- Початкова база: v0.9.4.1.
- Firestore Rules **не змінені**.
- Розрахункові модулі й формат документів **не змінені**.
- Відсутня міграція даних.
- Не включено особистий `.env`.

### Перевірка перед фінальним 1.0
1. Перенеси `.env`, виконай `npm.cmd install`, `npm.cmd test`, `npm.cmd run build`, `npm.cmd run dev`.
2. Перевір сторінки «Огляд», «Календар», «Статистика», «Нарахування», «Правила оплати».
3. Перемкни світлу, темну, автоматичну тему; перевір телефон/планшет та вузькі екрани.
4. Перевір перемикання робочих просторів, випадні меню, кнопки збереження, редактор дня, додаткові години, касу, план і премії.
5. Якщо помітиш проблему, повідом точну сторінку та розмір екрана.

### Статус збірки
У середовищі підготовки немає доступу до npm-реєстру (EAI_AGAIN). Тому повний `tsc -b && vite build` потребує запуску на твоєму комп'ютері. Автоматичні тести логіки та синтаксичні перевірки виконуються локально.
