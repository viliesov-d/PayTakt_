# Чекліст QA — PayTakt 2.0 Beta 3

- [ ] `npm.cmd test` — усі тести проходять.
- [ ] `npm.cmd run build` — TypeScript і Vite завершуються без помилок.
- [ ] Перехід між кроками майстра вперед і назад, чернетка зберігається після перезавантаження.
- [ ] Варіант «Немає понаднормових» пропускає питання про години.
- [ ] «Додаю кнопкою» +2 год/добу → шаблон 18:00–20:00 (для зміни 09:00–18:00), обраний тариф, кнопка календаря.
- [ ] «Автоматично» +2 год/добу → зміна 09:00–20:00, планова норма 8 год/день, доплата після порога.
- [ ] Значення 0,5 і 12 год приймаються, 0 і понад 12 відхиляються з поясненням.
- [ ] 24-годинний графік + додаткові автоматичні години відхиляються до збереження із зрозумілою підказкою.
- [ ] Магазин: каса доступна, виробництво: зайва каса прихована.
- [ ] «Інші можливості» займають окрему рівну картку, не стискаються поруч із кнопками.
- [ ] Розгортні блоки плавно відкриваються на ПК і телефоні, працюють із клавіатури та без анімації при Reduced Motion.
- [ ] Старі дні, ставки, каса й історія зберігаються після перепроходження майстра.
- [ ] Firebase: повторний вхід, зміна простору, збереження й читання після перезавантаження.
