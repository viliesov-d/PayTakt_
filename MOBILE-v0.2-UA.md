# PayTakt Mobile v0.2 — іконка, навігація і «Назад»

## Реалізовано

1. **Фірмова іконка PayTakt.** При Android-збірці замість стандартного значка
   Capacitor генерується календар з галочкою на темно-синьому фоні,
   у кольорах наявного `public/favicon.svg`. Створюються звичайні й адаптивні
   Android-іконки для всіх густин екранів.
2. **Нижня панель із трьома вкладками** тільки всередині Android-застосунку:
   «Календар», «Мої гроші», «Налаштування». На сайті наявна навігація не змінена.
3. **Навігація з історією.** Перехід між основними сторінками створює записи
   в історії WebView, тому системна кнопка Android «Назад» повертає
   до попередньої сторінки. На головній сторінці Android може закрити застосунок.
4. **Нижня системна панель і жестові індикатори.** Панель і основний контент
   мають відступи під безпечну область екрана.

### Що навмисно залишилося без змін

- Авторизація Firebase і Firestore; правил безпеки не змінювали.
- Сайт GitHub Pages (показує стару навігацію, без Android-вкладок).
- Зарплатний калькулятор, робочі зміни, статистика й налаштування.
- Редагування без мережі й заплановані сповіщення **ще не реалізовані**.

## Збірка нового тестового APK

1. Злити pull request `feature/android-mobile-v0.2` у `main`.
2. GitHub → Actions → **Android debug APK** → **Run workflow** (main).
3. Завантажити артефакт `PayTakt-Android-debug` і розпакувати APK.
4. Перед перевстановленням/видаленням звірити, що всі дані синхронізовані
   із сайтом. GitHub runner може підписувати кожен debug APK іншим ключем,
   тож **для цієї версії Android може вимагати видалити попередню тестову
   інсталяцію**; у цьому разі локальний кеш буде втрачено, Firebase-дані — ні.
5. Встановити новий `app-debug.apk` і перевірити вхід та календар.

## Чекліст на телефоні

- Логотип PayTakt видно на робочому столі (не іконку Capacitor).
- Нижня навігація має три вкладки та не перекриває вміст.
- Кнопка/жест «Назад» після переходу «Календар → Мої гроші» повертає в календар.
- Навігація сайту у браузері не змінилася.
- Збережені дні, ставка і статистика відповідають Firebase.

## Далі: v0.3

та виявленням конфліктів синхронізації; додати нативні локальні сповіщення

наявні перевірки мережі просто заради показового «офлайн».
