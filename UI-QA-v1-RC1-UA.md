# Чекліст PayTakt v1.0.0-rc.1

Перед фінальною версією 1.0.0 перевір:

- [ ] `npm.cmd run build` без TypeScript-помилок.
- [ ] Головна сторінка: великий темно-синій банер, міні-календар, лаймова кнопка.
- [ ] Верхнє меню відображає активну сторінку, всі пункти відкриваються.
- [ ] На телефоні кнопка меню розкриває навігацію й закриває її після переходу.
- [ ] Робочі простори перемикаються в хедері без втрати даних.
- [ ] Світла, темна й системна теми правильно застосовуються на всіх сторінках.
- [ ] Календар: заплановані дні, відпрацьовані, відпустка, вихідні та понаднормові.
- [ ] Редактор дня: кнопки типу/статусу дня, додавання понаднормових, каса й ручний заробіток.
- [ ] Правила оплати: розгортні секції, збереження окладу, авансу та премій.
- [ ] Статистика й виплати показують ті самі суми, що і до редизайну.
- [ ] На ширині 320–390 px немає горизонтального «зсуву» сторінки.
- [ ] Вихід з акаунта та повторний вхід працюють.

Дані у Firebase не перенось і не мігруй: у релізі змінено лише оформлення та нетехнічні повідомлення інтерфейсу.
