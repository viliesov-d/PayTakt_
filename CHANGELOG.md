# PayTakt 2.0.0 beta 2

- Окремий варіант «Вводжу заробіток сам» у майстрі; працює без плану, премії або обов'язкової фіксованої ставки.
- Новий крок «Понаднормові»: не потрібні / додавати кнопкою / автоматично після N годин за налаштованим відсотком.
- Ручний заробіток не залежить від перемикача планів; для понаднормових та нічних доплат є окрема погодинна база.
- Передача обраного тарифу для швидкої кнопки в збережений шаблон понаднормових.
- Персоналізація календаря: приховані неактуальні дії, каса доступна для відповідних сфер і за свідомим увімкненням в інших.
- У статистиці не показуються непотрібні блоки плану та понаднормових.
- Немає міграції Firebase; історичні дані не видаляються при приховуванні кнопок.
- Додано регресійні тести персоналізації, ручних нарахувань і понаднормових.

# Історія змін — PayTakt 2.0.0 beta 1

## Головне

- Новий повноекранний майстер налаштування для нового робочого простору.
- Рекомендації графіків і типів оплати залежать від обраної сфери діяльності.
- 17 сфер; скорочений початковий список, кнопка для перегляду всіх.
- Підтримка календарного 5/2 (Пн–Пт), циклів, нічних/добових графіків та власної послідовності робочих/вихідних.
- Ставка вводиться у гривнях і точно перетворюється на копійки без втрати двох знаків.
- Додаткові питання про понаднормові, нічні, касу, план та премії — лише якщо потрібні.
- Три базові шаблони виплат: половини місяця, фіксований аванс, єдина виплата.
- Екран підсумку з явним підтвердженням перед записом.
- Чернетка майстра зберігається локально для конкретного робочого простору.
- Стара система графіків, оплати, каси, статистики та премій залишена; доступна з розширених налаштувань.
- Після завершення — простіше меню з трьома головними сторінками.

## Сумісність і безпека

- Старі робочі простори з графіком або налаштуваннями оплати не змушують повторно проходити майстер.
- Збережені дні календаря не перезаписуються при початковому заповненні.
- Нічні, добові й комбіновані шаблони зберігають різний час змін (не застосовується один початок до всіх).
- Правила Firestore не змінювалися порівняно з релізом 1.0.0.

## Обмеження beta

- Початковий майстер заповнює лише поточний і наступний місяці, інші місяці — через редактор календаря.
- Для зміни графіка окремих днів комбінованого циклу використовується розширений редактор.
- Запис кількох документів виконується послідовно, тому при мережевій помилці можливе часткове збереження; повторний запуск не стирає наявні дні.
- Повну збірку з React/Vite у цьому середовищі не перевірено через недоступність npm-пакетів.

## v2.0.0-beta.3

- Нове умовне запитання про щоденні понаднормові години (0,5–12 годин) після вибору способу обліку.
- Синхронізація тривалості й тарифу з кнопкою календаря та правилами зарплати; автоматичні години не підвищують базову норму окладу.
- Вирівняна повноширинна картка «Інші можливості» та зведення активних налаштувань.
- Плавні анімації розгортання й підтримка Reduced Motion.
- Регресійні тести для умовних кроків, нічних змін, захисту планової норми, валідації та UI.
