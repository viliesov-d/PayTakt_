# PayTakt v0.9.4.1 — виправлення читання модуля «План і премії»

## Симптом

Після збереження плану сайт виводить:

> План і премії: План і премії: перевір показник, суму плану та кількість порогів. Перевір правила Firestore v0.9.4.

## Причина (підтверджена у вихідному коді)

У v0.9.4 `savePerformanceSettings()` записував поле `manualDailyPay`, а `subscribePerformanceSettings()` при читанні формував об'єкт без нього. У результаті локальний валідатор вимагав `manualDailyPay` як `boolean`, але отримував `undefined` і помилково повідомляв про неправильні правила/план.

## Виправлення

- `src/lib/performance.ts`: додано `parsePerformanceSettings()` для повного контрольованого перетворення документа. Для старого документа без `manualDailyPay` використовується `false`; якщо поле присутнє з неправильним типом, воно не приховується.
- `src/lib/data.ts`: Firestore-снимок розбирається через нову функцію, поле `manualDailyPay` не втрачається.
- `src/App.tsx`: після успішного завантаження прибирається стара помилка, а загальне повідомлення більше не стверджує безпідставно, що треба міняти Firestore Rules.
- Додані 5 регресійних тестів.

## Встановлення

1. Розпакуй архів у **нову папку**; не стирай стару робочу копію.
2. Перенеси тільки **свій локальний `.env`** із v0.9.4 (не поширюй цей файл).
3. **Firestore Rules не змінюй**: версія v0.9.4.1 не вводить нових полів або колекцій.
4. На Windows у PowerShell:

```powershell
npm.cmd install
npm.cmd test
npm.cmd run build
npm.cmd run dev
```

5. Відкрий «Правила оплати → План і премії», перевір відображення даних, зміни один параметр (за потреби) та збережи. Після перезавантаження сторінки помилка про некоректний план більше не повинна з'являтися.

## Дані і ризики

Місячні плани, денна каса, ручні заробітки, ставки, календарі та преміальні пороги не видаляються та не перезаписуються під час цього оновлення. Якщо помилка залишається, надішли нове точне повідомлення — воно може стосуватися іншої причини.

## Перевірка

Тести Node.js проходять. Компонентне ядро `src/lib/performance.ts` перевірене суворою перевіркою TypeScript. Повна Vite-збірка в цьому середовищі не підтверджена через відсутні npm-залежності.
