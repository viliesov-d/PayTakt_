# PayTakt 2.0 Beta 3 — прості налаштування, персональний календар

**Версія:** `2.0.0-beta.3`  
**База:** `2.0.0-beta.2`  
**Призначення:** тестова версія для перевірки перед стабільним релізом.

## Зміни

1. **«Інші можливості, якщо вони потрібні»** — окрема повноширинна картка у «Налаштуваннях роботи»; на телефоні кнопки й зведення розташовані вертикально. У картці тепер видно активні налаштування понаднормових, плану та ручної оплати, а касу можна ввімкнути незалежно від професії.
2. **Плавне відкриття блоків** — додано анімації розгортання/згортання для `<details>` (згортання анімоване в браузерах із підтримкою CSS `interpolate-size`; у старіших браузерах відкриття анімоване, закриття миттєве). Також анімовано меню та конструктор графіка. Режим «Зменшення руху» вимикає анімації.
3. **Умовне запитання майстра** — «Скільки годин понаднормових на добу?» показується **лише** при виборі ручних чи автоматичних понаднормових. Доступні швидкі варіанти 1–4 год та власне число від 0,5 до 12 год із кроком 30 хв.
4. **Додаткові параметри автоматично відповідають майстру.**
   - Кнопка «Додати понаднормові» отримує введені години, час після звичайної зміни та обраний тариф.
   - Автоматичний режим подовжує планову зміну на введену кількість годин, але **не збільшує планову норму окладу** (`plannedMinutes`). Понаднормові оплачуються після позначення дня як відпрацьованого за порогом і тарифом із майстра.
   - Відповіді про ручну оплату, план, касу й нічні доплати синхронізуються з уже існуючими правилами PayTakt.
5. **Порожні дні безпечно створюються**, раніше збережені не перезаписуються; режим майстра на існуючому просторі потребує підтвердження.

## Що не змінено

- Firebase-проєкт, Auth та Firestore Rules, формати зарплати й каси, тарифні обчислення, історія попередніх днів.
- Майстер зберігає план **поточного і наступного місяця**; інші місяці можна заповнювати через конструктор графіка.

## Перевірки

- 199 автоматичних тестів, включно з 8 новими сценаріями Beta 3.
- Сувора перевірка розрахункових TypeScript-модулів і синтаксична перевірка 24 TS/TSX-файлів.
- Повна React/Vite-збірка і робота з реальною базою **не перевірені**: у середовищі немає npm-залежностей і доступу до Firebase користувача.

## Як установити

1. Розпакуй ZIP в окрему папку, не видаляючи робочу Beta 2.
2. Перенеси особистий `.env` із Beta 2. Не завантажуй його у відкритий GitHub.
3. Запусти:

```powershell
npm.cmd install
npm.cmd test
npm.cmd run build
npm.cmd run dev
```

4. Створи тестовий робочий простір і пройди майстер для магазину: графік 5/2, ручний заробіток, «Додаю кнопкою», +2 год/добу, 120%, каса. Після завершення перевір кнопку +2 год, додаткові можливості та збереження після оновлення сторінки.
5. Другий сценарій: виробництво, оклад 31 000 грн, «Автоматично після норми», +2 год/добу. Переконайся, що робоча зміна подовжилась, норма залишилась 8 год, а каса прихована.

**Firestore Rules повторно публікувати не потрібно.**
