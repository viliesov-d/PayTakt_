# Оновлення PayTakt 2.0 Beta 2 → Beta 3

1. Зроби резервну копію своєї робочої Beta 2.
2. Розпакуй новий ZIP в окрему папку та перенеси `.env`.
3. Виконай `npm.cmd install`, `npm.cmd test`, `npm.cmd run build`, `npm.cmd run dev`.
4. У новому тестовому просторі пройди майстер. За наявності понаднормових перевір нове питання про кількість годин на добу.
5. У «Налаштуваннях роботи» відкрий «Інші можливості». Перевір вирівнювання на мобільному й десктопі, а також опис активних правил.
6. У календарі перевір швидку кнопку понаднормових або автоматичне нарахування; потім перезавантаж сторінку та переконайся, що вибрані значення збереглися.

**Нові правила Firestore не потрібні.** Не замінюй файл `firestore.rules` у робочому проєкті без потреби. Старі графіки та ставки не стираються автоматично.

Детальні сценарії — `BETA-QA-UA.md`; опис змін — `RELEASE-v2.0.0-beta.3-UA.md`.
