# PayTakt Mobile v0.6 — курси НБУ, видалення просторів і вихід

## 1. Курс валют із Національного банку України

- Джерело — **офіційний відкритий API НБУ**:
  https://bank.gov.ua/NBUStatService/v1/statdirectory/exchangenew?json
- Використовуються офіційні UAH-курси для USD, EUR, PLN, GBP.
- Під час відкриття PayTakt і повернення інтернету застосунок перевіряє,
  чи є курс, **вже завантажений сьогодні за датою Києва**.
  Один успішний мережевий запит на день кешується у localStorage.
- Якщо застосунок залишається відкритим, перевірка виконується щогодини,
  але новий курс завантажується тільки після зміни календарного дня в Києві.
- **Закритий застосунок не виконує фонових запитів**: актуалізація відбувається
  при наступному відкритті або поверненні онлайн.
- Показуються дата офіційного курсу НБУ та стан оновлення.
  При відсутності інтернету попередній курс зберігається з позначкою
  про застарілі дані. Якщо курсу взагалі немає — вибери ручний режим.
- Режими: автоматично НБУ (за замовчуванням) або курс вручну.
- **ВАЖЛИВО:** курси змінюють *лише еквівалент для відображення* UAH-простору.
  Вони **не змінюють гривневі суми у Firestore**.
  Якщо простір уже має валюту USD/EUR/PLN/GBP, зарплата ведеться
  безпосередньо у цій валюті та не конвертується автоматично.
- Офіційний курс НБУ — інформаційний орієнтир, а не курс продажу валюти
  у банку чи обміннику.

## 2. Видалення робочого простору

Налаштування → Робочі простори → «Видалити» поруч із потрібним простором.

**Безпека:** введи точну назву простору, щоб підтвердити.
Видалення незворотне; рекомендується перевірити синхронізацію або
зберегти потрібну інформацію наперед.

Механізм видалення:
1. Вимагати онлайн-сесію та автентифікацію власника.
2. Поставити на кореневому документі Firestore прапорець
   `deleting: true`. Нові записи у дочірніх колекціях **забороняються правилами**.
3. Послідовно зчитати дані **із сервера**, видалити всі відомі колекції
   пакетами по 80 документів: `shifts`, `scheduleTemplates`,
   `dailyCash`, `dailyWages`, `monthlyTargets`,
   `monthlySales`, `monthlyUnits`.
4. Окремо видалити відомі одиночні документи `settings/overtime`,
   `settings/cash`, `settings/performance`, `paySettings/current`.
5. **Однією атомарною операцією** видалити кореневий документ
   `workspaces/{id}` і запис-вказівник `users/{uid}/workspaces/{id}`.
6. Якщо мережа обірветься, простір залишається доступним для
   **повторного завершення видалення**. Кореневий документ та індекс
   не видаляються завчасно.

Обмеження: не можна видалити останній простір — спершу створи інший.
Ми очищаємо всі колекції, які наразі використовує PayTakt. Якщо у
майбутньому додадуться нові дочірні колекції, їх потрібно включити до
процедури. Для дуже великих корпоративних архівів рекомендоване
серверне рекурсивне видалення (Cloud Functions/Admin SDK), оскільки
Firestore не рекомендує масове видалення колекцій із мобільного клієнта.

## 3. Вихід із акаунта

- Налаштування → Мій профіль → **Вийти з акаунта**.
- Піктограма виходу в шапці залишається.
- Вихід доступний навіть на першому екрані майстра графіка.
- Використовується Firebase Authentication `signOut`:
  дані у хмарі не видаляються, для входу знову потрібен акаунт.

## 4. Обов'язково: опублікувати нові Firestore Rules

GitHub Actions та сайт не публікують правила автоматично.
Без змінених правил видалення не запрацює.

1. Дочекатися успіху `Validate Firestore Rules` та `Check PayTakt`.
2. У Firebase Console → Firestore Database → Rules зробити резервну
   копію діючого тексту.
3. Скопіювати **повністю** файл `firestore.rules` із цього PR.
4. Вставити його та натиснути **Publish**. Не використовуй відкриті
   правила `allow read, write: if true`.
5. Тоді об'єднати PR у `main`, запустити Android debug APK та встановити.
   Перед перевстановленням переконатися, що всі зміни синхронізовані.

## 5. Перевірки на телефоні

- У UAH-просторі Налаштування → Валюта відображення → USD →
  «Автоматично — офіційний курс НБУ»; показано дату та курс.
- Закрити/відкрити застосунок протягом дня — курс береться з кешу.
- Без інтернету залишається попередній курс з попередженням.
- Обрати «Вказати курс вручну» — автоматичний курс не перезаписує його.
- У просторі з USD нарахування залишаються USD, без подвійної конвертації.
- Створити **два тестових простори**, у другий додати невеликі тестові
  зміни, видалити його з підтвердженням. Перевірити, що перший не змінився.
- Налаштування → Мій профіль → Вийти з акаунта → знову увійти.
- Не тестуй безповоротне видалення на просторі з реальними цінними даними.

## 6. Автоматизовані перевірки

`tests/nbu-workspace-lifecycle.test.mjs` перевіряє валютні курси,
валідацію відповіді, добовий кеш і охоплення колекцій.
`tests/firestore-rules-delete.spec.mjs` перевіряє в емуляторі права
на видалення, блокування нових записів та фінальне атомарне очищення.
