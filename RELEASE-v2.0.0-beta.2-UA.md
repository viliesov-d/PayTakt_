# PayTakt 2.0.0 beta 2 — персоналізований календар

**Суть:** після майстра календар показує лише потрібні інструменти, з можливістю вручну додати виняткові функції через розширені налаштування. Магазин отримує доступ до каси, виробництво без відповідного вибору — ні. Вибір ручного заробітку доступний для всіх сфер.

Перевірка: `npm.cmd test`, `npm.cmd run build`, тестовий простір у Firebase, перезавантаження й сценарії з документа `PATCH-INSTRUCTIONS-UA.md`.

Beta — для тестування, не гарантована стабільна продукційна версія.
