# PayTakt v0.9 — календар і статистика

## Що нового

### Календар
- Показники вибраного місяця над календарем: підтверджені години, понаднормові та прогнозовані нарахування.
- Кнопка переходу до нової сторінки статистики.
- Підсвічування днів: усі / відпрацьовані / з понаднормовими. Непідсвічені дні залишаються доступними для редагування.
- Необов'язкові позначки дат виплат у комірках календаря: аванс, зарплата та премії, з урахуванням перенесення на наступні місяці.
- Для вибраного дня з виплатою — назва, місяць нарахування та прогноз суми (коли він доступний).
- Збережено швидкі кнопки статусу і понаднормових, конструктор графіка та захист від дублювання годин.

### Статистика
- Окрема сторінка «Статистика» в головному меню. Перемикання місяців.
- Планові дні/години, відпрацьовані години/зміни, понаднормові.
- Розподіл явних статусів дня: вихідні, відпустка, лікарняний, за свій рахунок.
- Динаміка годин за календарними тижнями та порівняння нарахувань за шість місяців.
- Прогноз виплат на вибраний календарний місяць за поточними правилами, включно з виплатами за попередні місяці.
- Зручні переходи до календаря, налаштувань оплати та деталізації нарахувань.
- Головний екран використовує ту саму логіку для підрахунку часу/понаднормових, що й статистика.

## Важливі обмеження

- Суми означають **нарахування за підтвердженою роботою**, а виплати — **прогноз за правилами**, НЕ банківські транзакції.
- Звіт за минулі місяці перераховується за поточними правилами оплати; історії ставок ще немає.
- Якщо оклад в режимі автоматичної норми не можна порахувати через відсутній графік, сума відображається як «—» / «Ще без суми», а не як 0.
- Підсвічування дня з понаднормовими включає також заплановані понаднормові. В нарахування потрапляють лише підтверджені.
- Дані поточного місяця можуть змінюватися після нових позначок роботи й бонусів.
- Не реалізовано облік фактично отриманих коштів або податкові відрахування.

## Firebase і сумісність

Формат документів і шляхи Firestore не змінювалися. `firestore.rules` у v0.9 такі самі, як у робочій v0.8.6. **Не змінюй успішно опубліковані правила для цього оновлення.** Поточні правила для `paySettings/current` містять відомий компроміс: перевірка власника і `version == 5`, але не кожного поля на сервері. Подальше посилення потрібно робити окремо з Firebase Emulator Suite.

## Встановлення (Windows PowerShell)

1. Розпакуй архів v0.9 у нову папку.
2. Перенеси **лише свої локальні змінні Firebase** з `.env` v0.8.6 (не публікуй цей файл).
3. У цій папці виконай:

```powershell
npm.cmd install
npm.cmd test
npm.cmd run build
npm.cmd run dev
```

4. Увійди в PayTakt та вибери раніше створений робочий простір. Перевір «Календар змін» і «Статистика».

### Перевірка релізу

Локально: Node-тести — 113 пройдено; сувора перевірка `src/lib/analytics.ts` — пройдена; синтаксис TypeScript/TSX змінених компонентів — перевірено. Повний `npm.cmd run build` **не запущено успішно** в середовищі створення через `EAI_AGAIN` при завантаженні npm-пакетів, тому обов'язково запусти його локально.
