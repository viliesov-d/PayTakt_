# PayTakt 1.0.0 RC2 — плавні анімації

Передрелізне оновлення дизайну RC1. **Формат даних, правила зарплати, календар виплат і Firestore Rules не змінювалися.**

## Що додано

- Легкий перехід між розділами; верхнє меню на мобільному плавно розгортається.
- Календар плавно змінює місяць: стрілки відповідають напрямку руху, клітинки з'являються послідовно.
- Обраний день, позначка «Відпрацьовано», понаднормові, каса й виплати змінюють оформлення плавно. Оптимістичне збереження, як у RC1, залишається миттєвим.
- Розділи налаштувань і модальні вікна відкриваються м'яко, кнопки реагують на натискання, графіки та індикатори плану плавно оновлюються.
- Ледь помітне «плавання» декоративного календарика і монет на головній сторінці.
- Анімації вимикаються для користувачів із системною опцією «Зменшення руху» (`prefers-reduced-motion: reduce`).

## Встановлення на Windows

1. Розпакуй RC2 в нову папку й перенеси `.env` із RC1.
2. Виконай `npm.cmd install`, `npm.cmd test`, `npm.cmd run build`, `npm.cmd run dev`.
3. Перевір перемикання місяців уперед/назад, кнопку «Сьогодні», підтвердження дня й понаднормові, різні теми та мобільне меню.
4. Перевір системну опцію зменшення руху: календар має залишатись повністю функціональним без анімацій.

Firestore Rules повторно публікувати не потрібно. Приватний `.env` у пакет не входить.

## Обмеження перевірки

Автоматичні тести та синтаксис TS/TSX/CSS можна перевірити в цьому середовищі. Повна Vite-збірка потребує встановлених npm-пакетів, недоступних у поточному середовищі, тому її слід виконати локально.
