# PayTakt 2.0 Beta 4 — персоналізація календаря

- «Графік під твої правила» тепер доступний у «Налаштування роботи».
- Порядок календаря, плану та статистики й видимість необов’язкових блоків можна змінювати в календарі. Налаштування зберігаються на цьому пристрої окремо для кожного workspace.
- План і прогрес за місяць — відразу під календарем; показники «Відпрацьовано», «Понаднормові», «Нараховано» — нижче.
- На телефонах «Обраний день» відображається над календарем.
- Ручний заробіток і каса — одна компактна форма: 0 означає введений нуль, порожнє поле — видалення відповідного запису. Каса та зарплата лишаються окремими документами.
- Покращено шрифти та іконки мобільної версії; Safari більше не має автоматично масштабувати поля з малим шрифтом, але pinch-zoom не заборонено.
- Firebase Rules, база даних та формули зарплати не змінювалися.

## Перевірки
GitHub Actions: npm test, npm run typecheck, npm run build та публікація Pages.
